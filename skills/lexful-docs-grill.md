# Documentation grill

Use when asked to challenge a draft or when a material choice prevents a document from being actionable. Start from the user's notes, existing draft, or wayfinder handoff. Resolve factual gaps from authorized sources where possible. Separate known facts, missing evidence, and decisions only the user or an approver can make.

Build a decision tree. For each open choice record what it blocks, viable options, the recommended answer and trade-off, and any dependent choices. Prioritize decisions that change the next action. For example, settle the offboarding cutoff and successor acceptance before asking who revokes access. In a change plan, settle acceptable downtime before proposing the rollback threshold. Skip cosmetic choices and proceed with a labeled assumption for reversible details.

Ask the highest-impact unblocked question. State the recommendation, why, and the main trade-off. Phrase it so a simple yes accepts the recommendation. Wait for the answer, record it, then recompute what is unblocked. Keep a decision pending if the evidence is insufficient or the responsible approver has yet to weigh in.

When the remaining questions no longer block the document, hand back the selected document type, settled decisions and rationale, source links, and open items with owners where known. Continue into the specialist draft when requested. A decision made in this conversation does not authorize a Lexful write or an operational action.
