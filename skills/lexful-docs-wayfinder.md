# Documentation wayfinder

Identify who needs the document, what they need to do next, and whether the work is routine, planned, active, or complete. Use the user's notes and authorized records first. If choosing incorrectly would change the draft materially, ask one focused question and give two concrete options.

- Routine repeatable work calls for an SOP. A live alert calls for a runbook. A resolved incident calls for an incident review.
- A one-time rollout calls for a change plan. A repeatable check that proves recovery calls for a backup and restore test.
- A client transition calls for onboarding or offboarding. A durable reference to the systems involved calls for an environment overview.
- A client decision meeting calls for a QBR brief. A request to define repeatable agent behavior calls for a skill design.

Choose one starting document. Briefly name the outcome and any assumptions, then load the specialist and start the draft when enough context is available. Carry forward known evidence and mark gaps. If the specialist is unavailable, draft against the known outcome and disclose that the specialist guidance was unavailable. Return the draft or focused question directly. Avoid routing back to `/lexful-docs`. Keep Lexful writes scoped to the operation the user requested.

Once the format is clear, hand off to `/lexful-docs-grill` if a consequential decision blocks a usable draft. Pass the selected specialist and the open decisions.
